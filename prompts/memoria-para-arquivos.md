# Prompt: tirar a memória do app e pôr no repositório

Abra a memória do projeto no app (configurações do projeto → memória), copie o texto e cole junto com:

```text
Este é o que a memória automática aprendeu comigo. Para cada item, diga onde ele deve morar no
repositório <dono>/<repo>:
- regra de comportamento → contexto/regras.md (uma linha, com data);
- passo de um processo → a skill certa em contexto/skills/ (ou uma skill nova);
- fato do negócio → contexto/negocio.md, voz.md ou publico.md;
- coisa velha ou repetida → descartar.
Mostre a proposta antes de gravar.
```
