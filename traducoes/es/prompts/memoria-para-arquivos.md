# Prompt: sacar la memoria de la app y ponerla en el repositorio

Abre la memoria del proyecto en la app (configuración del proyecto → memoria), copia el texto y pégalo junto con:

```text
Esto es lo que la memoria automática aprendió de mí. Para cada elemento, di dónde debería estar en el
repositorio <dueño>/<repo>:
- regla de comportamiento → contexto/regras.md (una línea, con fecha);
- paso de un proceso → la skill adecuada en contexto/skills/ (o una skill nueva);
- dato del negocio → contexto/negocio.md, voz.md o publico.md;
- algo viejo o repetido → descartar.
Muestra la propuesta antes de guardarla.
```
