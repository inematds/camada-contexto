# AGENTS.md — capa de contexto

Este repositorio es la **fuente de la verdad** de mi negocio. Es válido para Claude, Codex y cualquier agente.

## Antes de cualquier trabajo
1. Lee `contexto/negocio.md`, `contexto/voz.md`, `contexto/publico.md` y `contexto/regras.md`.
2. Si la tarea tiene una skill en `contexto/skills/`, sigue esa skill.
3. Las nuevas decisiones van en `contexto/decisoes.md` (fecha + decisión + motivo).

## Cómo escribir aquí
- Trabaja directamente en la branch `main` (esto es contexto, no software: nada de branches).
- Lo que produzcas (textos, hojas de cálculo, guiones) va en `entregas/`.
- No borres ni cambies el nombre de un archivo sin preguntar.
- Nunca guardes una contraseña, un token o una clave de API en este repositorio.
- Los datos que cambian todo el tiempo (tareas, clientes, registros) no van aquí: quedan en la base de datos.
