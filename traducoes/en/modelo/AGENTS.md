# AGENTS.md — context layer

This repository is the **source of truth** for my business. It applies to Claude, Codex, and any agent.

## Before doing any work
1. Read `contexto/negocio.md`, `contexto/voz.md`, `contexto/publico.md`, and `contexto/regras.md`.
2. If the task has a skill in `contexto/skills/`, follow that skill.
3. Add new decisions to `contexto/decisoes.md` (date + decision + reason).

## How to write here
- Work directly on branch `main` (this is context, not software: no branches).
- Put anything you produce (texts, spreadsheets, scripts) in `entregas/`.
- Do not delete or rename a file without asking.
- Never save a password, token, or API key in this repository.
- Data that changes constantly (tasks, clients, records) does not belong here: it belongs in the database.
