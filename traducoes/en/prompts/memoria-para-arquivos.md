# Prompt: move memory out of the app and into the repository

Open the project memory in the app (project settings → memory), copy the text, and paste it together with:

```text
This is what automatic memory has learned about me. For each item, say where it should live in the
repository <owner>/<repo>:
- behavior rule → contexto/regras.md (one line, with date);
- process step → the right skill in contexto/skills/ (or a new skill);
- business fact → contexto/negocio.md, voz.md, or publico.md;
- outdated or repeated item → discard.
Show me the proposal before saving it.
```
