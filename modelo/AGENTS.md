# AGENTS.md — camada de contexto

Este repositório é a **fonte da verdade** do meu negócio. Vale para Claude, Codex e qualquer agente.

## Antes de qualquer trabalho
1. Leia `contexto/negocio.md`, `contexto/voz.md`, `contexto/publico.md` e `contexto/regras.md`.
2. Se a tarefa tiver uma skill em `contexto/skills/`, siga a skill.
3. Decisões novas vão em `contexto/decisoes.md` (data + decisão + motivo).

## Como escrever aqui
- Trabalhe direto na branch `main` (isto é contexto, não software: nada de branches).
- O que você produzir (textos, planilhas, roteiros) vai em `entregas/`.
- Não apague nem renomeie arquivo sem perguntar.
- Nunca grave senha, token ou chave de API neste repositório.
- Dado que muda toda hora (tarefas, clientes, registros) não mora aqui: fica no banco de dados.
