Em resumo

Este é um kit grátis para guardar o contexto do seu negócio (o que você faz, a sua voz, o seu público, as suas regras) num repositório privado que é seu, e não dentro de um app de IA. O Claude e o ChatGPT/Codex leem e escrevem nesse mesmo lugar, então você não fica com duas cópias que se desencontram nem preso a uma empresa. O kit traz a estrutura de pastas, um bloco único de instruções para os dois apps, prompts prontos e um verificador que barra senha e banco de dados antes do envio. Para usar, basta uma conta grátis no GitHub e o Claude ou o ChatGPT.

O que é

Três camadas, uma só é sua

Os apps de IA agora trabalham na nuvem deles. Ótimo para ficar ligado o tempo todo; ruim quando o seu contexto fica preso lá dentro.

🤖 Em cima: a IA

Onde o trabalho roda: Claude, Codex ou a próxima IA. Ela muda; o resto fica.

🌉 No meio: a ponte

Git, conector MCP ou API. Cada app precisa da sua própria permissão para passar.

🗄️ Embaixo: o que é seu

Os arquivos do seu negócio, num repositório privado. Troque a IA, mantenha a fonte.

Guia · passo a passo

A camada em 6 passos

Primeiro clone o kit. Os comandos rodam dentro da pasta dele.

git clone https://github.com/inematds/camada-contexto
cd camada-contexto
1

Entenda o problema das duas cópias

Quando você sobe o contexto em cada app separado, nascem duas versões do seu negócio. Cada semana elas ficam um pouco mais diferentes, e quem guarda o seu contexto prende você ali.

2

Separe arquivo de dado vivo

Arquivo muda pouco: negócio, voz, público, decisões, skills. Isso é texto em markdown, no repositório. Dado vivo muda toda hora: tarefas, clientes, registros. Isso vai num banco na nuvem (como o Supabase), nunca numa pasta de arquivos.

3

Escolha onde guardar

Sozinho ou em equipe pequena: GitHub, grátis, privado e com histórico de cada mudança. Equipe não técnica: Notion, feito para várias pessoas editarem juntas. Drive: antes, confira se o conector do app consegue editar os arquivos, não só ler.

4

Monte o repositório privado

Crie um repositório privado no GitHub. Gere a estrutura com o kit, preencha e confira antes de enviar. Se você já tem uma pasta de contexto, use o prompt para o agente copiar tudo no lugar certo.

scripts/iniciar.sh ~/minha-empresa-contexto
python3 scripts/checar_contexto.py ~/minha-empresa-contexto
# OK: 0 bloqueio(s) … — senha, banco de dados e planilha são barrados
cat prompts/copiar-contexto.md
5

Ligue os dois apps com o mesmo bloco

Conecte o GitHub no Claude e no ChatGPT/Codex e cole o mesmo bloco nas instruções do projeto de cada um: o repositório é a fonte da verdade, leia antes de agir, escreva na main, não apague sem perguntar, nunca grave senha.

cat instrucoes/bloco-projeto.md
6

Tire a memória de dentro do app

O que a memória automática aprendeu com você não deve ficar presa lá. Regra vai para contexto/regras.md; passo de processo vai para uma skill; fato do negócio vai para o arquivo do negócio.

cat prompts/memoria-para-arquivos.md
A prova

O teste dos dois agentes

Um cria, o outro edita. Se os dois conseguem, a ponte funciona nos dois sentidos.

1

O Codex cria

Peça ao Codex para criar entregas/teste-ponte.md no repositório.

2

O Claude edita

Peça ao Claude para abrir o mesmo arquivo e acrescentar uma linha.

3

Você confere

O arquivo tem as duas linhas? Então os dois trabalham no mesmo contexto.

cat prompts/teste-dois-agentes.md
