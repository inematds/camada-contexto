En resumen

Este es un kit gratuito para guardar el contexto de tu negocio (qué haces, tu voz, tu público, tus reglas) en un repositorio privado que te pertenece, y no dentro de una app de IA. Claude y ChatGPT/Codex leen y escriben en ese mismo lugar, así que no tienes dos copias que se desincronizan ni dependes de una empresa. El kit incluye la estructura de carpetas, un bloque único de instrucciones para ambas apps, prompts listos y un verificador que bloquea contraseñas y bases de datos antes del envío. Para usarlo, solo necesitas una cuenta gratuita de GitHub y Claude o ChatGPT.

Qué es

Tres capas, solo una es tuya

Las apps de IA ahora trabajan en su propia nube. Es genial para estar siempre conectado; no tanto cuando tu contexto queda atrapado allí.

🤖 Arriba: la IA

Donde se ejecuta el trabajo: Claude, Codex o la próxima IA. Ella cambia; el resto permanece.

🌉 En medio: el puente

Git, conector MCP o API. Cada app necesita su propio permiso para acceder.

🗄️ Abajo: lo que es tuyo

Los archivos de tu negocio, en un repositorio privado. Cambia de IA, conserva la fuente.

Guía · paso a paso

La capa en 6 pasos

Primero clona el kit. Los comandos se ejecutan dentro de su carpeta.

git clone https://github.com/inematds/camada-contexto
cd camada-contexto
1

Entiende el problema de las dos copias

Cuando subes el contexto por separado a cada app, aparecen dos versiones de tu negocio. Cada semana son un poco más diferentes, y quien guarda tu contexto te mantiene atado allí.

2

Separa los archivos de los datos vivos

Los archivos cambian poco: negocio, voz, público, decisiones, skills. Son texto en markdown, en el repositorio. Los datos vivos cambian a cada rato: tareas, clientes, registros. Van en una base de datos en la nube (como Supabase), nunca en una carpeta de archivos.

3

Elige dónde guardar

Si trabajas solo o en un equipo pequeño: GitHub, gratis, privado y con historial de cada cambio. Para un equipo no técnico: Notion, pensado para que varias personas editen juntas. Drive: antes, comprueba si el conector de la app puede editar los archivos y no solo leerlos.

4

Crea el repositorio privado

Crea un repositorio privado en GitHub. Genera la estructura con el kit, complétala y revísala antes de subirla. Si ya tienes una carpeta de contexto, usa el prompt para que el agente copie todo en el lugar correcto.

scripts/iniciar.sh ~/minha-empresa-contexto
python3 scripts/checar_contexto.py ~/minha-empresa-contexto
# OK: 0 bloqueo(s) … — se bloquean contraseñas, bases de datos y hojas de cálculo
cat prompts/copiar-contexto.md
5

Conecta ambas apps con el mismo bloque

Conecta GitHub en Claude y ChatGPT/Codex y pega el mismo bloque en las instrucciones del proyecto de cada uno: el repositorio es la fuente de la verdad, lee antes de actuar, escribe en main, no borres nada sin preguntar y nunca guardes contraseñas.

cat instrucoes/bloco-projeto.md
6

Saca la memoria de la app

Lo que la memoria automática aprendió de ti no debe quedar atrapado allí. Las reglas van a contexto/regras.md; los pasos de un proceso, a una skill; los datos del negocio, al archivo del negocio.

cat prompts/memoria-para-arquivos.md
La prueba

La prueba de los dos agentes

Uno crea y el otro edita. Si ambos pueden hacerlo, la conexión funciona en ambas direcciones.

1

Codex crea

Pídele a Codex que cree entregas/teste-ponte.md en el repositorio.

2

Claude edita

Pídele a Claude que abra el mismo archivo y agregue una línea.

3

Tú lo compruebas

¿El archivo tiene ambas líneas? Entonces los dos trabajan con el mismo contexto.

cat prompts/teste-dois-agentes.md

modelo/
